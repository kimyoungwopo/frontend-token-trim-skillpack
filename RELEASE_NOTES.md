# v0.1.0

Initial public release of Frontend Token Trim Skillpack.

## Highlights

- Hermes Agent native skillpack with `ponytail`, `graphify`, `headroom`, and `frontend-token-trim`.
- Codex, Claude, and OpenClaude rule templates.
- Korean, English, and Japanese documentation.
- Visual workflow diagrams and controlled token benchmark.
- Install and update scripts with backups outside active skill discovery.
- GitHub Actions validation and upstream `ponytail` sync PR automation.

## Install

```bash
git clone https://github.com/kimyoungwopo/frontend-token-trim-skillpack.git
cd frontend-token-trim-skillpack
./install.sh
```

## Update

```bash
./update.sh
```
