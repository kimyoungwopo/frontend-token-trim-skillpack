# Changelog

All notable changes to Frontend Token Trim Skillpack are documented here.

This project follows a lightweight semantic versioning style:

- `MAJOR`: breaking install/layout or skill contract changes
- `MINOR`: new skills, templates, automation, or docs
- `PATCH`: fixes, copy edits, validation improvements

## v0.1.0 - 2026-08-01

Initial public release.

### Added

- Hermes Agent skillpack with `ponytail`, `graphify`, `headroom`, and `frontend-token-trim`.
- Codex, Claude, and OpenClaude rule templates.
- Korean, English, and Japanese documentation.
- Workflow SVGs and Mermaid flow diagrams.
- Controlled token benchmark and estimator script.
- `install.sh` installer with timestamped backups outside active skill discovery.
- `update.sh` for git-clone based user updates.
- Weekly upstream sync workflow for `DietrichGebert/ponytail` that opens reviewable PRs.
- Validation workflow for scripts, docs, required skills, templates, and assets.
- MIT license and third-party NOTICE.
