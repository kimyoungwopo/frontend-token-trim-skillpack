# Roadmap

Frontend Token Trim stays focused on one promise: **read less, change less, verify more**.

## v0.2.0 — Adoption tools

- Install doctor for Hermes skill discovery and backup conflicts.
- Agent rule installer for Codex, Claude, OpenClaude, and generic agents.
- `skillpack.json` manifest for versioned package metadata.
- Modes documentation for light, strict, and review usage.
- Frontend QA checklist.
- Mobile overflow example.
- Social preview assets.

## v0.3.0 — Presets and benchmark suite

- Framework presets: Next.js, Vite, Tailwind, shadcn/ui.
- Benchmark cases for mobile overflow, design-token reuse, API state bugs, and modal accessibility.
- Benchmark suite runner and aggregate result document.

## v0.4.0 — Agent run analyzer

- Transcript analyzer for over-read, over-change, missing QA, and final report quality.
- Report schema for comparing agent runs.
- Scorecard output for PR review.

## v0.5.0 — Team adoption

- Team rule pack generator for `AGENTS.md`, `CLAUDE.md`, `.cursor/rules`, and PR templates.
- Project-specific presets and policy overlays.
- Migration guide for teams adopting frontend AI coding agents.

## v1.0.0 — Stable frontend agent work standard

- Stable skill contract.
- Stable CLI/script surface.
- Multi-case benchmark evidence.
- Framework preset coverage for common frontend stacks.
